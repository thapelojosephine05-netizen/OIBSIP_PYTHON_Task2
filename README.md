The objective of this project is to calculate a person's Body Mass Index (BMI) using their weight and height.

The steps i perfomed:
1. Asked the user to enter their weight in kilograms.
2. Asked the user to enter their height in metres.
3. Converted the user's inputs into floating-point numbers using `float()`.
4. Calculated BMI by dividing weight by height multiplied by itself.
5. Used `if`, `elif`, and `else` statements to classify the BMI result.
6. Displayed the BMI value and the corresponding weight category.

The cateories
- Underweight: BMI below 18.5
- Normal weight: BMI from 18.5 to 24.9
- Overweight: BMI from 25.0 to 29.9
- Obese: BMI of 30 or above

Tools i used
- Python
- Visual Studio Code

The outcome
I developed a working BMI Calculator that accepts the user's weight and height, calculates their BMI, and displays their weight category.

what i learned
Through this project, I practised using variables, user input, floating-point numbers, mathematical calculations, and conditional statements in Python.
